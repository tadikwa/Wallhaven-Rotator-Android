# Privacy

Wallhaven Rotator Android is designed without project telemetry, analytics, advertising or tracking.

The application contacts:

- `wallhaven.cc` for SFW wallpaper search metadata;
- Wallhaven image hosts for the selected wallpaper files.

Application settings, cache metadata and wallpaper history remain in the app's private local storage. The cache is excluded from Android cloud backup/device transfer rules.
